# КОНТРАКТ: `fund-tracker/1`

> Замороженный контракт данных для **третьего раздела платформы — «Трекер фондов»**.
> Дашборд уже построен на нём и работает на фикстуре. Движок обязан выдать файл этой
> формы; при `fixture: false` баннер «демо-данные» исчезает сам, правок кода не требуется.

```
движок (еженедельно)  →  handoff/fund_tracker.json
     →  ab-investment/src/data/fundTracker.json
          →  src/data/fundTracker.js        (адаптер)
               →  components/research/funds/ (раздел)
```

---

## 0. Что это за объект и чем он НЕ является

| | Потоки | Экосистема ИИ | **Трекер фондов** |
|---|---|---|---|
| Узел | Аллокатор / получатель | Сущность | **Фонд** |
| Ребро | Сделка | Позиция власти | **нет и не будет** |
| Природа | Событие с датой | Стоящая позиция | **Книга на дату среза** |
| Размер узла | Капитал | Критичность | **Размер книги** |
| Цвет узла | Сектор / класс | Слой | **Движение книги за период** |
| Обновление | Еженедельно | Ежемесячно | **Еженедельно** |

Между фондами **нет осмысленных связей**. Раздел рисует узлы без рёбер и живёт своей
маршрутизацией: отдельный пункт в выпадающем списке карт, отдельное состояние,
отдельная панель. Не сводить его к карте потоков.

**Отслеживаются 14 фондов целиком.** Ещё четыре (Citadel, Millennium, Point72,
Balyasny) — мульти-стратегии и маркет-мейкеры: их книга есть инвентарь сотен pod-ов,
а не мнение. Они попадают в раздел **только сработавшими правилами** (`class: "watch"`,
непустой `triggers[]`) и никогда — целой книгой.

## 1. Корень файла

```jsonc
{
  "schema": "fund-tracker/1",
  "version": "1.0",
  "generated": "2026-08-21",     // ISO. ВОЗРАСТ ВСЕХ СТРОК СЧИТАЕТСЯ ОТ НЕЁ, не от «сегодня»
  "fixture": false,              // true → дашборд печатает баннер «демо-данные»
  "fixture_note": null,          // текст баннера, если fixture
  "cycle":  { "period": "2026Q2", "period_end": "2026-06-30", "filing_deadline": "2026-08-14" },
  "guards": { … },               // §6
  "style_tags": { "<key>": { "label": "…", "blurb": "…" } },
  "sectors":    { "<key>": "Ярлык" },
  "themes":     { "<key>": "Ярлык" },
  "totals":     { "funds", "watch", "positions", "book_value_usd", "events",
                  "stakes", "shorts", "securities" },
  "funds":      [ Fund ],        // 14 tracked + N watch, в одном массиве
  "events":     [ FundEvent ],   // лента, любой порядок — дашборд сортирует сам
  "securities": { "<TICKER>": Security }
}
```

Все ярлыки (`style_tags`, `sectors`, `themes`) приходят **из файла**. Дашборд не хранит
второй копии — он хранит только ЦВЕТ стиля и порядок стилей; новый `style_tag` от движка
отрисуется сразу, просто нейтральным цветом. Добавляя стиль, скажите — заведём цвет.

## 2. `Fund`

```jsonc
{
  "id": "pershing-square",              // стабильный, машинный, не меняется между циклами
  "name": "Pershing Square Capital Management, L.P.",
  "short_name": "Pershing Square",      // то, что видно на узле и в таблице
  "principal": "Билл Акман",            // по-русски
  "style_tag": "activist",              // ключ из style_tags
  "class": "tracked" | "watch",
  "cik": "0001336528",
  "aum_usd": 18400000000,               // капитал фирмы; null если не раскрывается
  "book_value_usd": 12900000000,        // РАСКРЫТАЯ книга на дату среза
  "position_count": 10,                 // живых позиций (без закрытых)
  "as_of":  "2026-06-30",               // конец периода самого свежего источника книги
  "filed":  "2026-08-12",
  "source_form": "13F-HR",              // §5
  "latency_days": 52,                   // generated − as_of; дашборд пересчитает, если нет
  "sparse_coverage": false,             // true → постоянный флаг «раскрытие неполно»
  "why_tracked": "…", "focus": "…", "strategy": "…",   // §7 — единственная проза
  "conviction": { … },                  // §2.2; null для watch
  "activity":   { "new": ["FNMA"], "added": [], "trimmed": [], "exited": [] },  // тикеры
  "positions":  [ Position ],           // §2.1; пусто для watch
  "stakes":     [ Stake ],              // §3
  "shorts":     [ Short ],              // §4
  "returns":    [ { "year": 2026, "pct": 9.4, "provisional": true, "source_url": null } ],
  "entities":   [ { "name": "…", "cik": "…", "role": "parent" | "child" } ],
  "triggers":   [ Trigger ]             // ТОЛЬКО для class: "watch"
}
```

`returns[].provisional: true` обязателен для незакрытого года — дашборд рисует такой
столбец пунктиром и печатает сноску, как в панели аллокатора раздела 2.

`entities[]` — **сведение к управляющему**. Позиции агрегируются к родителю по умолчанию;
дочерние сущности существуют как раскрытие, а не как отдельные узлы. Фонд не должен
появляться трижды по трети своего настоящего размера.

### 2.1 `Position`

```jsonc
{
  "ticker": "CMG", "issuer": "Chipotle Mexican Grill", "cusip": null,
  "weight": 0.0929,                  // доля книги, 0–1
  "shares": 5300000,
  "value_usd": 1200000000,
  "instrument": "common" | "adr" | "call" | "put" | "note",
  "action": "new" | "added" | "trimmed" | "exited" | "hold",
  "share_delta_pct": 0.107,          // ПО АКЦИЯМ, не по деньгам. null для new/hold, −1 для exited
  "prior_shares": 4787000,
  "quarters_held": 15,
  "sector": "consumer", "theme": "consumer_brands",
  "jurisdiction": "US" | "UK" | "DE" | "ES" | "FR" | "JP" | "CA" | "AU",
  "source_form": "13F-HR", "as_of": "2026-06-30", "filed": "2026-08-12",
  "latency_days": 52,
  "source_url": "https://www.sec.gov/…",     // каждое число ведёт к своей форме
  "price_change_pct_in_period": -0.11,
  "added_into_weakness": true                 // action=added И цена падала
}
```

- **`share_delta_pct` считается ПО ЧИСЛУ АКЦИЙ и никогда по деньгам.** Долларовая дельта
  смешивает сделку с движением цены и делает колонку бессмысленной.
- Закрытая позиция остаётся строкой: `weight: 0`, `shares: 0`, `prior_shares > 0`,
  `action: "exited"`, `share_delta_pct: -1`.
- **Опцион (`put`/`call`) в 13F показан по номиналу** (страйк × 100 × контракты), а не по
  риску. Дашборд помечает такие строки отдельным чипом с этим предупреждением —
  не пересчитывайте номинал в «размер ставки» на стороне движка.
- `added_into_weakness` — самый сильный одиночный признак во всём наборе. Считать строго:
  число акций выросло **и** `price_change_pct_in_period < 0`.

### 2.2 `conviction`

```jsonc
{ "score": 84,                       // 0–100, сводная оценка движка
  "top10_concentration": 0.91,       // доля книги в десяти крупнейших
  "avg_persistence_quarters": 11.2,
  "turnover": 0.11,
  "added_into_weakness": ["CMG", "NKE"] }   // тикеры, а не объекты
```

## 3. `Stake` — 13D/13G

```jsonc
{ "issuer": "Howard Hughes Holdings", "ticker": "HHH",
  "form": "SC 13D" | "SC 13D/A" | "SC 13G" | "SC 13G/A",
  "pct_outstanding": 0.469, "filed": "2026-05-19", "event_date": "2026-05-07",
  "latency_days": 5, "activist": true,
  "intent": "…краткое изложение Item 4…",     // проза, рендерится дословно
  "source_url": "https://www.sec.gov/…" }
```

Активистские формы — строки с самой высокой информативностью в разделе; они получают
отдельное оформление. `activist: true` ставится, когда в Item 4 заявлено намерение
влиять на управление или контроль, а не когда форма просто называется 13D.

## 4. `Short` — реестры EU/UK

```jsonc
{ "issuer": "Ocado Group plc", "isin": "GB00B3MBS747",
  "jurisdiction": "UK", "register": "FCA",
  "pct_short": 0.0081, "as_of": "2026-08-20", "latency_days": 1,
  "direction": "new" | "increased" | "decreased" | "closed",
  "source_url": "…" }
```

Редкие и ценные — именно потому, что короткую ногу в США не видно вовсе. Не хоронить в
хвосте фонда; в панели у них своя секция.

## 5. Формы и их латентность

`source_form` обязателен на КАЖДОЙ позиции, событии и триггере. Слои приходят с разной
скоростью, и пользователь должен видеть, какой именно он читает:

| Форма | Типичная задержка |
|---|---|
| `13F-HR` | до 45 дней после конца квартала — строке может быть 4,5 месяца |
| `13F-HR/A` | поправка; снятие режима конфиденциальности — **самое редкое и громкое событие раздела** |
| `N-PORT` | ежедневное раскрытие ETF — латентность один день |
| `4` | два рабочих дня от сделки |
| `SC 13D` | пять дней от пересечения 5%, с заявленным намерением |
| `SC 13G` | пассивная форма |
| `TR-1` | ЕС/Великобритания, 2–4 дня — **вне периметра 13F** |
| `Short register` | ежедневно, EU/UK |

Неамериканские позиции (UK TR-1, ЕС, Япония, Канада, Австралия) идут в том же массиве
`positions`, помеченные `jurisdiction`. Часто это самые информативные строки — ровно
потому, что 13F их не видит.

## 6. `guards` — экранные предохранители

```jsonc
{ "min_weight_for_delta": 0.005,
  "min_weight_note": "Процентное изменение на позиции легче 0,5% книги не показывается…",
  "stale_after_days": 45,
  "very_stale_after_days": 90 }
```

Оба предохранителя реализованы в дашборде и не подлежат отключению:

1. **Процент изменения скрывается на мелких позициях.** Крупный процент на крошечной
   строке драматичен и ничего не значит. Ниже порога число не приглушается, а не
   показывается вовсе — приглушённое неверное число остаётся неверным. Единственное
   исключение — закрытие позиции: −100% это вся позиция, а не процент от осколка.
2. **Флаг «новая позиция» никогда не рендерится без своей латентности.** Новая позиция
   из 13F может быть четырёхмесячной давности, и фонд из неё уже вышел.

## 7. Проза — ровно четыре поля

`why_tracked`, `focus`, `strategy` у фонда и `intent` у доли. Всё. Дашборд **не
генерирует ни одного предложения** и рендерит эти поля дословно. Никаких комментариев,
никаких «как читать эту позицию», никакой воды. Всё остальное на экране — числа.

`why_tracked` — одна-две фразы о том, что делает фонд *запоминающимся*, а не ещё одним
именем в списке. Это то, ради чего он в разделе.

## 8. `FundEvent` — лента

```jsonc
{ "id": "pershing-square-stake-0", "date": "2026-05-19",
  "fund_id": "pershing-square", "fund": "Pershing Square",
  "type": "13f" | "13f_amendment" | "13d" | "13g" | "form4" | "tr1"
        | "short_register" | "ark_trade" | "n_port" | "watch_trigger",
  "ticker": "HHH" | null,
  "headline": "…одна строка, по-русски, факт без интерпретации…",
  "magnitude_usd": 118000000,        // null, если неприменимо
  "latency_days": 2, "source_form": "SC 13D/A",
  "source_url": "…", "loud": true }
```

`loud: true` — самые редкие и информативные типы (поправка 13F, 13D, TR-1, реестр
шортов, триггер наблюдения). Дашборд даёт им отдельное оформление и фильтр
«только сигнал».

## 9. `Trigger` — как watch-сущность попадает в раздел

```jsonc
{ "rule": "stake_crossing" | "amendment_release" | "tr1_crossing"
        | "form4_insider" | "unusual_concentration",
  "ticker": "VRT", "issuer": "Vertiv Holdings", "form": "SC 13G/A",
  "filed": "2026-07-14", "event_date": "2026-06-30", "latency_days": 14,
  "headline": "…почему это вообще заметно…",
  "magnitude_usd": 1940000000, "pct_outstanding": 0.052, "source_url": "…" }
```

Пустой `triggers[]` → сущность не появляется на экране вообще. Это и есть их правило
попадания: интересны не они, а те редкие моменты, когда их книга что-то говорит.

## 10. `Security` — таблица держателей

```jsonc
"NVDA": {
  "ticker": "NVDA", "issuer": "NVIDIA",
  "shares_outstanding": 18200000000,
  "tracked_holders": 6,
  "holders": [
    { "holder": "The Vanguard Group", "fund_id": null, "tracked": false,
      "shares": 835000000, "value_usd": null, "pct_outstanding": 0.0459,
      "change_shares": -68000000, "change_pct": -0.075, "action": "trimmed",
      "filed": "2026-08-14", "source_form": "13F-HR", "latency_days": 52 }
  ]
}
```

Полный институциональный реестр, а не только отслеживаемые. Именно он показывает,
рано или поздно отслеживаемый фонд зашёл в имя относительно всей институциональной базы.
Достаточно ключа на каждый тикер, встречающийся в `positions`.

## 11. Чего движку делать НЕ надо

- Не считать «сигналы» и не писать интерпретаций — раздел числовой.
- Не переводить номинал опционов в размер риска.
- Не сглаживать латентность и не подставлять «сегодня» вместо даты среза.
- Не разворачивать `entities` в отдельные фонды.
- Не выдавать watch-сущности с книгой: только `triggers[]`.
- Не молчать о неполноте: `sparse_coverage: true` там, где раскрытие структурно неполно
  (family office). Тонкая запись не должна читаться как «тихий квартал».
