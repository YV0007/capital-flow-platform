# Экосистема — контекст для передачи

Читать целиком перед первым действием. Здесь два репозитория, два конвейера и один
замороженный контракт между ними. Половина ошибок в этой задаче — от того, что
правку сделали на той стороне, где её делать нельзя.

Файл описывает **состояние на 2026-08-18, 15:50**.

---

## 1. Что это такое

В разделе «Исследования → Карта потоков капитала» живут **две карты** за общим
переключателем. Состояния не пересекаются по построению: оболочка
`src/components/research/CapitalFlowSection.jsx` монтирует одну ИЛИ другую, поэтому
фильтры, панели, поиск и выделение физически не могут смешаться.

| | **Потоки** | **Экосистема** |
|---|---|---|
| Вопрос | куда ушли деньги на прошлой неделе | как устроена отрасль и кто её держит |
| Узел | получатель или аллокатор | компания |
| Ребро | сделка, поток денег | **стоячая зависимость** |
| Размер узла | капитал | **критичность** |
| Конвейер | недельный, `run_week.py` | **месячный, `run_month.py`** |
| Таблицы БД | обычные | **`eco_*`** |

Обе карты рисуются одним и тем же «капитальным атомом»: ядро в центре, острова по
кругу, узел — плитка-иконка, рёбра — волосяные бонды force-graph. Это сознательно:
карты должны быть неразличимы на ощупь и различаться только тем, О ЧЁМ они.

## 4. Дашборд — как он устроен

### Файлы

| Файл | Роль |
|---|---|
| `EcosystemMap.jsx` | оболочка на весь экран: состояние, фильтры, линзы, режим цепочки, переключатель карта/таблица |
| `EcoGraph.jsx` | холст. Тот же художник, что `capitalflow/FlowGraph` |
| `ecoLayout.js` | раскладка. `packRelative`/`relax`/`hash01` **импортируются** из `capitalflow/layout.js`, а не копируются |
| `EcoEntityPanel.jsx` | панель компании справа |
| `EcoEdgeCard.jsx` | карточка связи снизу по центру, аналог `FlowDetailCard` |
| `LayerReport.jsx` | отчёт по слою; открывается кликом по подписи острова |
| `ChainCrumbs.jsx` | цепочка как предложение, под картой |
| `EcoTable.jsx` · `EcoFilterBar.jsx` · `Glossed.jsx` · `chain.js` | таблица, фильтры, подсветка терминов, обход цепочки |

### Адаптер `src/data/ecosystemMap.js`

Единственное место, которое знает формат файла. Он же держит **мета-таблицы
отображения**: роль → цвет/форма, тип ребра → подпись и хребет, тир → вес линии,
рубрика критичности со словесными шкалами. Ни одного имени компании, слоя или сектора
в JSX нет — это критерий приёмки: подмена JSON не требует правок кода.

Что адаптер делает поверх данных, не меняя их: считает возраст по `lastConfirmed`
относительно `asOf` (старше 6 мес. — узел блёкнет), выводит `solid` из правила двух
источников, **выбрасывает ребро с висячей ссылкой** с `console.warn` (полсвязи хуже,
чем ничего), склеивает `logoUrls`, `site`, `profile` из сайдкаров.

### Визуальный язык — и что уже отвергнуто

Первая версия рисовала 12 концентрических колец, радиальные капсулы и рёбра
порт-в-порт. Выброшено целиком: колесо читается как мишень, а не как отрасль.
**Не возвращать: кольца, капсулы, пунктир для одного источника, красную подсветку
узлов.** Причины — в `ECOSYSTEM-DASHBOARD-BUILD-LOG.md` §0.

Настройки, добытые перебором (крутить их, а не переписывать раскладку):

- `packTiles` в `ecoLayout.js` — упаковка по **настоящему следу плитки**
  (полудиагональ квадрата ≈ 1.31·r плюс место под подпись), иначе каждая компания
  недобронирована на 31% и подписи налезают;
- размер узла `r = 9 + 29·(критичность/100)^0.85` — корень из капитала здесь не
  годится, критичность это рубрика 0–100, а не степенной закон;
- рёбра: прозрачность 0.26–0.54, ширина 0.26–0.74. Кривая карты потоков подаёт долю
  от общего, крошечную почти для всех потоков; здесь на вход идёт 0–100, и та же
  формула прижимала почти каждый бонд к полной непрозрачности;
- `GAP_CELL = 250`, зазор между ячейками 170, зазор от ядра 185.

## 5. Контракт передачи

Заморожен и **двусторонний**: та же схема слово в слово лежит в
`ECOSYSTEM-BUILD-PROMPT-ENGINE.md` у движка. Ни одна сторона не меняет его в одиночку.
Если нужна правка — остановиться и спросить.

```
generated, asOf, source ("engine" | "fixture"), ecosystem
totals   { nodes, edges, layers, cycles }
layers[] { id, label, caption, band, concentration{level,hhi,top[]} } × 12
sectors[]{ key, label, layer, dcNode }
nodes[]  { id, name, role, sector, layers[{layer,primary,criticality}],
           criticality, criticalityFactors{}, gravity{}, oneLiner, whatBreaksIt,
           ticker, publicPrivate, geo, tier, techNodes[], dcNode,
           firstSeen, lastConfirmed, stale }
techNodes[] { id, label, owner, note }
edges[]  { id, source, target, type, spine, strength, techNode, status, tier,
           confirmedSources, engineConfirmed, started, lastConfirmed, note, evidence[] }
cycles[] { id, type, path[], edges[], note }
changelog{ month, added[], removed[], changed[] }
```

Зафиксированы также: таксономия 12 слоёв, рубрика критичности с весами
`0.30 · 0.30 · 0.25 · 0.15`, тиры источников, порог strength.

**Расхождение, которое уже произошло.** В отданном файле у узлов есть поле
`shareNote`, которого в контракте нет. Дашборд его не читает. Кто-то добавил поле в
одностороннем порядке — это ровно то, чего контракт запрещает. Надо решить: внести в
контракт с обеих сторон или убрать из движка.

## 6. Что произойдёт в момент подмены — с цифрами

Скопировать `handoff/ecosystem_map.json` → `src/data/ecosystemMap.json` — это одна
команда, и код править не надо. Но результат будет не таким, как сейчас на экране:

**Карта уменьшится.** 62 → 44 компании, 107 → 57 связей. Выпадают, среди прочих,
Alphabet, Meta, AMD, Marvell, Applied Materials, Cadence, KKR, GIP, Ibiden,
Digital Realty, Hugging Face, Crusoe, Coherent, Corning, Eaton, GE Vernova. Контуров,
наоборот, станет больше: 5 → 7.

**Идентификаторы у движка ДРУГИЕ.** Совпадает только **23 из 44**. Движок пишет
полные слаги, фикстура — короткие:

| движок | фикстура |
|---|---|
| `arm-holdings` | `arm` |
| `micron-technology` | `micron` |
| `ase-technology` | `ase` |
| `amkor-technology` | `amkor` |
| `carl-zeiss-smt` | `zeiss-smt` |
| `super-micro-computer` | `smci` |

Следствие: **21 компания из 44 останется без логотипа и без досье** — знак
превратится в монограмму, описание схлопнется до однострочника. А 39 из 62 записей в
`ecosystemProfiles.json` будут указывать в пустоту. Оба сайдкара надо перебить на
идентификаторы движка. Это первое дело после подмены; **правильнее — попросить
движок зафиксировать схему id, иначе то же самое повторится каждый месяц.**

**Доказательная база слабее, чем на фикстуре.** Правило двух источников выполнено на
**1 ребре из 57 (2%)** против 19 из 107 (18%) на фикстуре. То есть 56 связей на карте
будут стоять на одном источнике. Это не дефект дашборда — это честное состояние
исследования после первого прогона, и главный показатель, за которым стоит следить
из месяца в месяц.

**Мелочи.** `changelog` пуст — сравнивать было не с чем, это первый прогон.
`techNode` заполнен у 21% рёбер, `started` — у 44%. L12 в отданном файле всё ещё
`РЕЗУЛЬТАТ`: переименование в `AI-ЛАБОРАТОРИИ` внесено в промпт движка позже прогона
и подхватится следующим.

**Плашки «черновые данные» больше нет.** Она снималась сама по полю `source`, но её
убрали по просьбе владельца. Сейчас на экране ничто не говорит, что карта на
выдуманных данных. После подмены это перестанет быть проблемой, но пока — помнить.

## 7. Открытые вопросы — вероятная повестка разговора

1. **Забирать ли файл движка сейчас** и как чинить сайдкары: перебивать руками или
   договариваться о стабильной схеме id.
2. **`shareNote`** — узаконить в контракте или убрать.
3. **Объём в деньгах на ребре.** Карточка связи показывает «что идёт» (тех-узел) и
   существенность 0–100. Денег в контракте нет вообще. Если они нужны — это правка
   контракта, двусторонняя.
4. **Досье как поле движка.** Сейчас абзацы пишет дашборд. Прецедент есть: прозу
   сигналов на карте потоков движок уже забрал себе. Логично забрать и это.
5. **`scripts/fetch_logos.py`** ходит только по `capitalMap.json`. Под вторую карту не
   расширен — ждали, пока устоится состав узлов.
6. **Подписи компаний налезают друг на друга** внутри острова. Упаковка учитывает
   плитку, но не подпись, которая вшестеро шире. Предложено: проход по коллизиям на
   отрисовке — более критичная компания оставляет имя, соседняя показывает по
   наведению. Не сделано.
7. **L11 `ИНФЕРЕНС`** — такой же жаргон, каким был L12 `РЕЗУЛЬТАТ`. Не переименован.

## 8. Правила работы

- **Контракт двусторонний.** Не менять в одиночку ни с какой стороны.
- **Дашборд не считает ничего сам.** `criticality`, `gravity`, `concentration`,
  `cycles` приходят посчитанными. Дашборд только показывает.
- **Никогда не читать целиком** `src/data/*.json` — это 200–400 КБ и 50–100К токенов.
  `grep`, потом `Read` с `offset`/`limit`.
- **`npm run build` перед каждым push.** Не проходит — не пушить.
- Коммиты короткие: `Экосистема: что сделано`. Много мелких лучше одного большого.
- Push в `main` — Vercel деплоит сам.
- **Осторожно: над этими файлами могут работать две сессии сразу.** Так уже было
  сегодня, и это дало пустой экран из-за импорта файла, который ещё не дописали.
  Перед правкой стоит проверить `git status` и время изменения файлов.
