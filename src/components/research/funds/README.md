# Трекер фондов — третий раздел платформы

> Карта потоков отвечает «куда пошли деньги на неделе». Экосистема — «кто держит
> отрасль». Этот раздел — **«что четырнадцать фондов на самом деле держат и что
> изменили»**.

Чистый потребитель `src/data/fundTracker.json` (контракт `fund-tracker/1`, заморожен в
корневом `FUND-TRACKER-CONTRACT.md`). Ничего не исследуется и не вычисляется здесь сверх
арифметики, записанной в коде. Подменить файл следующей поставкой движка — и раздел
изменится без единой правки кода.

```
движок  →  handoff/fund_tracker.json  →  src/data/fundTracker.json  →  fundTracker.js  →  сюда
```

## Почему это не карта

| | Потоки | Экосистема | **Фонды** |
|---|---|---|---|
| Узел | Аллокатор / получатель | Сущность | **Фонд** |
| Ребро | Сделка | Позиция власти | **нет** |
| Размер | Капитал | Критичность | **Размер книги** |
| Цвет | Сектор / класс | Слой | **Движение книги за период** |

Четырнадцать независимых фондов не связаны между собой ничем осмысленным. Нарисовать
ребро значило бы заявить отношение, которого нет. Поэтому: та же словарная база узла —
плитка, монограмма, волосяная рамка, моноширинная подпись, много воздуха — и **никаких
связей**. Переключатель разделов живёт уровнем выше, в `../CapitalFlowSection.jsx`: он
монтирует одно и размонтирует другое, состояния не пересекаются по построению.

**DOM-сетка, не canvas.** Восемнадцати узлам не нужны пан и зум, а DOM бесплатно даёт
чёткий текст, настоящие цели клика и hover. Раскладка детерминированная: кластеры по
`style_tag` в порядке таксономии, внутри — по размеру книги. Тот же файл → та же
картинка при каждой перезагрузке.

## Два предохранителя — не оформление, а корректность

Оба живут в коде и не отключаются:

1. **`showDelta(weight)` / `<Delta>`** — процент изменения на позиции легче
   `guards.min_weight_for_delta` **не показывается**. 89% сокращения в инвентаре
   маркет-мейкера драматичны и не значат ничего. Число не приглушается, а скрывается:
   приглушённое неверное число остаётся неверным. Исключение — закрытие позиции: −100%
   это вся позиция, а не процент от осколка.
2. **`<LatencyBadge>`** обязателен рядом с любым числом, пришедшим из формы. Строка 13F
   может быть 135-дневной; Form 4 — двухдневный. Отрисовать их одинаково — ошибка
   корректности, а не вкуса. Флаг «новая позиция» никогда не рендерится без возраста.

## Файлы

| | |
|---|---|
| `../../../data/fundTracker.js` | **адаптер**: таксономия (стили, действия, формы, инструменты, юрисдикции, типы событий), полосы латентности, тепловая шкала активности, пересечения (`CROSSING`, `CROWDED`). Данным свободы не даёт. |
| `FundTracker.jsx` | оболочка: верхняя панель, переключатель видов, поиск, семантика фильтров, общее состояние выделения. |
| `FundGrid.jsx` | узлы без связей + полоса «под наблюдением» + легенда цвета. |
| `FundPanel.jsx` | панель фонда — ядро раздела. Только числа. |
| `FundTable.jsx` | две таблицы: по фондам и по позициям, сортировка по любому столбцу. |
| `FundTimeline.jsx` | лента всех событий раскрытия, новые сверху, фильтр «только сигнал». |
| `HolderLookup.jsx` | пересечение: фонд → бумага и бумага → весь институциональный реестр. |
| `FundFilters.jsx` | ящик фильтров, та же грамматика чипов, что и у карт. |
| `FundBits.jsx` | общие атомы, включая оба предохранителя и `useTone()` для светлой темы. |
| `fundFormat.js` | форматтеры; деньги и склонения импортируются из `../capitalflow/format.js`, не переписываются. |

## Что уже отвергнуто

- **Рёбра между фондами.** Любой их вид — «оба держат NVDA», «оба активисты» — это
  свойство строки, а не отношение между фондами. Для «оба держат» есть колонка
  «Фондов» и фильтр пересечения; для «оба активисты» — кластер.
- **Force-раскладка и canvas.** Восемнадцать узлов, детерминированная сетка. См. выше.
- **Генерируемый текст.** Никаких «как читать эту позицию». Проза — только четыре поля
  из файла (`why_tracked`, `focus`, `strategy`, `intent` у доли), дословно.
- **Долларовая дельта.** Изменение позиции считается по числу акций. Долларовое
  смешивает сделку с движением цены.
- **Watch-сущности целой книгой.** Citadel и соседи входят в раздел только сработавшим
  правилом. 8412 позиций маркет-мейкера — инвентарь, а не мнение.

## Логотипы

Фонды используют монограммные плитки (`<FundMark>`), а не лого-пайплайн: `npm run logos`
ходит по узлам `capitalMap.json` и о фондах ничего не знает. Неверное лого хуже, чем его
отсутствие; монограмма честна. Если понадобится — расширять `scripts/fetch_logos.py`
отдельным проходом по `fundTracker.json`.

## Фикстура

`scripts/make_fund_fixture.mjs` собирает демонстрационный `fundTracker.json` с
`fixture: true` — раздел печатает постоянный баннер «демо-данные». **Числа выдуманы.**
Когда придёт поставка движка (`fixture: false`), баннер исчезнет сам; скрипт после этого
удалить.
