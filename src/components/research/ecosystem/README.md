# Экосистема — вторая карта секции Capital Flow

> Сначала понять, как устроена отрасль. Потом смотреть, куда в ней идут деньги.

Карта потоков (`../capitalflow/`) отвечает на вопрос «куда пошли деньги на неделе».
Эта — на вопрос «как отрасль устроена и кто её держит».

| | Потоки | Экосистема |
|---|---|---|
| Узел | Аллокатор / получатель | **Компания** |
| Ребро | Сделка: сумма, дата | Зависимость: поставка, контракт, владение |
| Природа | Событие с датой | **Стоящая позиция**, без даты |
| Размер узла | Капитал | **Критичность** — насколько незаменим |
| Координата | Сектор (угол) | **Слой стека (радиус)** + сектор (угол) |
| Обновление | Еженедельно | **Ежемесячно** |

Две карты **не делят состояние**. Переключатель «Потоки | Экосистема» живёт уровнем выше,
в `../CapitalFlowSection.jsx`: он монтирует одну из двух и размонтирует другую, поэтому
фильтры, панели, поиск и выделение раздельны по построению, а не по договорённости. Общие
только оболочка и утилиты: `capitalflow/canvasTheme.js`, `capitalflow/format.js`,
лого-пайплайн, паттерны зума и панорамы.

## Контракт данных — ЗАМОРОЖЕН

Единственная точка стыковки с движком. Ни одна сторона не меняет его в одиночку.

```
~/Desktop/Capital Flow/                        ← движок (агенты + Python + SQLite)
   └── ЕЖЕМЕСЯЧНЫЙ конвейер
         → handoff/ecosystem_map.json
              → ab-investment/src/data/ecosystemMap.json
```

**Железные правила**

1. `nodes[].id` и `edges[].id` стабильны между прогонами. Переименование = потеря истории.
2. `edges[].source` / `target` ссылаются на `nodes[].id`. Висячих ссылок быть не может —
   адаптер такое ребро **выбрасывает** и пишет `console.warn`.
3. `evidence` непустой для каждого ребра. Нет цитаты — нет ребра.
4. `layers` всегда 12 записей.
5. **Дашборд не считает ничего сам.** `criticality`, `gravity`, `concentration`, `cycles`
   приходят посчитанными. Здесь только рисование.
6. Контракт не меняется в одностороннем порядке.

### Черновые данные

Пока `source !== "engine"` карта показывает плашку «Черновые данные — ждём первый прогон
движка», а каждая цитата в панели помечается «черновик». Плашка читает поле из самого
файла, поэтому исчезает сама — правок кода не требуется. Другой разницы в поведении нет.

Текущий `ecosystemMap.json` — фикстура на 45 компаний и 61 связь вокруг цепочки
`ASML → TSMC → NVIDIA → Foxconn → CoreWeave → OpenAI` и хребта капитала
`Brookfield → Westinghouse → Constellation → Microsoft`. Она правдоподобна, но не проверена.

## Таксономия — фиксирована

Источник истины: `../dc/Roadmap.jsx` (`LAYERS` + `NODES_RAW`). Слой = радиус кольца,
`band` = одна из 5 цветовых полос.

| id | label | band | id | label | band |
|---|---|---|---|---|---|
| L1 | СЫРЬЁ | 1 | L7 | ПЕРЕДАЧА ТОКА | 3 |
| L2 | ОБОРУДОВАНИЕ | 1 | L8 | СВЯЗЬ | 4 |
| L3 | ЧИПЫ | 2 | L9 | СИСТЕМЫ | 4 |
| L4 | ПАМЯТЬ | 2 | L10 | ВЫЧИСЛЕНИЯ | 4 |
| L5 | СБОРКА | 3 | L11 | ИНФЕРЕНС | 5 |
| L6 | ГЕНЕРАЦИЯ | 3 | L12 | РЕЗУЛЬТАТ | 5 |

**Рубрика критичности** (веса фиксированы, считает движок):

`criticality = round(100 × (0.30·share + 0.30·alternatives + 0.25·switchTime + 0.15·barrier) / 5)`

Проверка: ASML 5/5/5/5 → **100**; ODM-сборщик 2/1/1/1 → **26**.

**Тиры источников:** `filing` · `company_pr` · `transcript` → сплошная линия;
`press` · `estimate` → пунктир. Плюс правило двух источников: `confirmedSources >= 2` →
сплошная, `== 1` → пунктир независимо от тира. `status: "unverified"` или
`lastConfirmed` старше 6 месяцев → узел/ребро блёкнет.

**Порог strength:** в файл пишется всё; на карте по умолчанию рисуются рёбра
`strength >= 20`, ползунок опускает до 0. **В панели узла список связей всегда полный** —
зависимость, которую не видно из-за положения ползунка, забывается.

## Геометрия — почему так

**Кольца.** Слой = радиус: `L1` в центре, `L12` на краю. Отсюда главное свойство карты —
цепочка поставок рисуется **лучом из центра наружу**, а не клубком. Это и есть аргумент за
кольца против «солнц».

**Капсула.** Компания в нескольких слоях — **один узел**, растянутый по радиусу от нижнего
своего слоя к верхнему. Толщина в каждом слое = критичность именно там; между слоями, где
компании нет, — тонкая перемычка со спиной и точкой на каждом занятом слое. Alphabet — одна
капсула через L3 · L10 · L12, а не три кружка. Побочный выигрыш: вертикальная интеграция
становится **формой**.

**Точки стыковки.** Ребро рисуется не между центрами узлов, а между их **портами нужного
слоя**: цепочка через облако входит в Alphabet на L10 и выходит на L12. Ради этого капсула
и делается.

**Угол.** Внутри кольца узлы сгруппированы по сектору. Порядок секторов вокруг круга — не
алфавит и не порядок файла, а **круговая сериация** по силе связей: сектора, которые
торгуют друг с другом, оказываются рядом, поэтому вертикальные нити стека стоят на одном
пеленге. Подробности и компромиссы — в комментариях `ecoLayout.js` и в
`ECOSYSTEM-DASHBOARD-BUILD-LOG.md`.

**Коридор.** Сверху (12 часов) оставлена свободная полоса под подписи 12 колец — они
единственный кликабельный текст на канвасе и открывают отчёт по слою. Узлами остаются
только компании.

## Взаимодействие

- **Клик по компании** → карта гаснет, загорается её цепочка по стеку. Контролы:
  глубина (1 шаг · 2 шага · вся цепочка), направление (вверх · вниз · обе),
  тип связи (всё · физика · контроль). Ветвление обрезается до топ-5 по существенности,
  остальное — «ещё N» по клику.
- **Крошки под картой** — тот же путь словами: `ASML —поставляет→ TSMC —поставляет→ NVIDIA`.
  Каждая крошка перецепляет цепочку на себя.
- **Клик по подписи кольца** → отчёт по слою.
- **Круги** — линза замкнутых контуров: сбыт красным, финансирование янтарным.
  Единственная линза без оценок: цикл есть свойство графа.
- **Esc** — сброс.

## Логотипы

Контракт не несёт домена, поэтому знаки резолвятся в три шага:

1. `logoManifest.json` — файлы, которые `npm run logos` уже скачал для карты ПОТОКОВ.
   Многие компании здесь те же юрлица, поэтому находятся по имени (`alloc:NVIDIA`,
   `target:…`) и переиспользуются бесплатно.
2. `ecosystemLogos.json` — сайдкар `id → домен`, из него строятся unavatar/favicon-ссылки.
3. Монограмма.

`scripts/fetch_logos.py` ходит по `capitalMap.json` и про эту карту пока не знает —
расширять его под `ecosystemMap.json` имеет смысл после первого настоящего прогона движка,
когда состав узлов устоится.
